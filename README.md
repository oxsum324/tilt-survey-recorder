## 試填流程

1. 在「案件與表頭」填表頭，或按「載入範本合成示例」。示例會取代目前案件，頁內對話框可先匯出。
2. 在「立面參數」調整樓高、女兒牆、寬度、側立面長度。模式 C 須先設定兩點法或由左至右方位角。
3. 在「測點與讀數」新增測點組，選 A、B、C 作業方式。填妥後按「確認本組讀數」。
4. 在「點位照片」拍攝或匯入影像，按 TP／TB 快捷鍵，先點測點，再點文字框位置。可圈選、畫箭頭、自由筆、文字、復原／重做及橡皮擦。長按有放大鏡。原圖不改寫，日期戳記可編輯或隱藏。
5. 在「平面圖標示」匯入底圖，填來源及截圖／製圖日期；選測點組，在底圖點 ●，再拖動兩個編號文字框。可放大、拖曳瀏覽，或用 Ctrl＋V 貼圖。更換底圖會先確認並清除平面位置，讀數與照片保留。
6. 在「成果與輸出」預覽每頁 2 組、每組 2 方向的 A4 成果表，預設附原始讀數表。
7. 使用「系統列印／另存 PDF」，選 A4、直向、100% 比例，關閉瀏覽器自行加入的頁首／頁尾。系統列印保留向量圖及可選取文字。「下載影像式 PDF」另提供直接下載；字體為影像，不可選取。照片附件和佈設圖可獨立輸出，不要求讀數完成。
8. 離開現場前按「匯出案件檔」，確認 `.tiltsurvey` 已保存。此檔含原始讀數、各模式保留資料、更正原因與時間、照片／底圖原始 bytes、照片標註及平面位置。影像每張最多 60 MB；原始媒體合計最多 175 MB，案件檔最多 250 MB。

## 作業方式

| 方式 | 輸入 | 結果 |
|---|---|---|
| A 直接偏移量 | ΔX（cm）與方向、H（cm）；或上／下尺讀數 | 立面內、立面外各 1～2 回 |
| B HD／VD | TP、TB 的 HD、VD（m）與測站位置 | 一個測站一個方向；VD 可為負值 |
| C N／E／Z | 一組 TP／TB 座標（m），立面基準 | 同組資料同時得到兩方向；合成參考值只在原始表 |

方向皆以觀看者站在立面外、面向立面為準：立面內正向向右，立面外正向向後（朝建物內側）。儀器 X／Y 不自動轉成 N／E。

原始讀數以字串保存，十進位換算採有理數，座標相減後才投影，保留小於 1 mm 的資訊。表列 ΔX 與 H 最後四捨五入至整數 mm，顯示 0.1 cm；分母採表列 H ÷ ΔX 四捨五入。兩回取有號位移平均。V0.3.0 對 B／C 兩回 H 不同的情況先要求一致後才出成果，採用策略待確認。

## 保存與離線

IndexedDB 資料庫 `tilt-survey-v1`，project 與 media 分開保存。草稿自動保存；已確認讀數改動後須填更正原因，否則不產生成果預覽。切換模式保留原資料。可匯出完整案件檔並再匯入；匯入取代前可先匯出、直接取代、取消。案件檔是可編輯 JSON，不是防竄改或簽章文件。

第一次連線成功並顯示「離線資源已準備」後，可離線重新開啟。Service Worker 快取名稱 `tilt-survey-v0.3.0`，所有路徑皆相對於專案子目錄。新版完整資源下載後會啟用，下次重新整理載入新介面。若從 V0.1.0 升級，先匯出案件備份、連線重新整理，確認頁首 V0.3.0；若仍顯示舊版，再重新整理一次。資料庫與案件格式維持相容。

資料不會上傳 GitHub，裝置與瀏覽器間不會同步；清除網站資料、無痕視窗或瀏覽器儲存空間被回收都可能移除本機案件。完整案件檔應另行保存。

## 本版範圍與實機測試

依使用者追加要求完成照片拍攝／標註與平面圖標示，並串接照片頁、佈設圖、直接下載影像式 PDF、強光模式與螢幕常亮。原始案件照片、範本 PDF、內部資料蒐集文件未納入 repo。本工具記錄與計算，不作安全判定、補償估算或施工前後比較。

強光與螢幕常亮偏好存在裝置上，不寫入案件。強光模式不會改變輸出報告或照片色彩，螢幕亮度由裝置調整。常亮預設啟用；頁面隱藏會釋放，返回後再次申請，顯示實際狀態（已啟用／已暫停／不支援／已關閉）。電量、權限或瀏覽器策略可能拒絕。請用 iPhone／Android 實機測試相機、貼圖、長按定位、切換分頁和長時間常亮；瀏覽器自動測試不代表實機已驗收。

照片日期先讀 EXIF DateTimeOriginal；無 EXIF 時明示使用匯入時間（臺灣時間），不採檔案修改時間。EXIF 未驗證時區。輸出日期戳記另存，不改寫原始拍攝時間。標註 JPEG 最長邊最多 4096 px；案件備份保留未縮圖原檔。底圖的編號文字大小以 A4 紙張尺寸決定，不隨匯入像素數改變。

## 開發與驗證

```powershell
npm.cmd ci --ignore-scripts
npm.cmd test
npm.cmd run test:browser
npm.cmd start
```

瀏覽器測試使用 Playwright；Windows 用已安裝 Google Chrome，其他環境使用 Chromium。若需要，先安裝 `npx playwright install chromium`。本機預覽 `http://127.0.0.1:8789/`。應透過伺服器或正式網址開啟，不能雙擊 index.html。

測試只使用合成資料。截圖與實際 PDF 檢視紀錄在 `output/playwright/` 與 `output/media/`（不提交）。GitHub Actions 先跑單元測試，將明列的程式檔複製到 Pages；不直接發布整個工作目錄。`node tests/live.mjs` 比對線上部署清冊與全部程式檔雜湊。

## 案件資料指紋與分享

案件檔附 SHA-256，鍵值排序後計算，包含原始讀數、確認／更正紀錄、照片標註、佈設位置及每個引用媒體原檔的 SHA-256。成果表與原始讀數表頁尾列前 16 碼，附件末頁列完整 64 碼。

案件檔中的媒體必須與案件引用完全對應；未引用、重複或缺少原檔均拒絕匯入與指紋驗證，不會略過額外媒體而顯示一致。舊檔未附指紋時也適用此完整性檢查。

排除欄位：appVersion、createdAt、updatedAt、lastExportedAt、nextPairIndex、settings.defaultMode。這些欄位記錄軟體版本、保存／匯出時間及新增預設，不改變既有量測內容。瀏覽器的強光、常亮與目前分頁偏好不屬於案件資料。

「驗證案件檔指紋」只在記憶體計算，不匯入、不覆蓋目前案件；舊檔未附指紋時只能計算，無法聲稱一致。指紋用於比對內容，並非身分簽章或第三方認證。

支援檔案分享的裝置顯示「準備分享案件檔」，完成媒體讀取與指紋計算、確認實際檔案可分享後，改顯示「分享已準備的案件檔」。再次點擊才直接呼叫系統分享，讓大型案件準備耗時不影響操作授權。編輯或取代案件會作廢已準備的檔案，須重新準備。取消分享不更新匯出時間；分享進行中有新變更時，新變更仍列為未匯出。

## 分方向作業方式與舊案件

每個方向的 mode 可為 A／B／C，空字串表示沿用測點組預設。切換測點組預設會讓兩方向重新沿用；可再對單一方向選取其他方式，所有替代讀數均保留。任一方向採 C 時只輸入一組共用座標；A 的共用垂距不會代替 B／C 由讀數計算的垂距。

schema 維持 1。V0.4.0 以前或未附 appVersion 的舊案件，兩方向一律承接原測點組設定，包括曾殘留其他方向 mode 的案件；這與舊版計算程式的優先順序一致。V0.4.0 起保留方向各自的選擇及空字串沿用設定。原確認快照不改寫，更正仍須填原因。

## 發布清單與私人字串

只發布 build-site.mjs 明列的檔案。private-denylist.txt 為本機忽略檔，每行一個私人字串；可參考 private-denylist.example.txt 的示例格式。CI 由使用者設定 TILT_PRIVATE_DENYLIST secret（換行分隔）；兩個來源合併檢查，均未提供時會警告並僅套用通用路徑規則。這次只清理新 HEAD，既有公開 Git 歷史未改寫。

## V0.4.1 手機讀數流程

640 px 以下使用單列可捲動步驟；「狀態」展開本機保存、離線、強光與常亮。頁面說明由標題旁的「說明」開啟。匯出、匯入、驗證及支援裝置的分享，位於案件頁與成果頁底部。

讀數頁底部摘要列可點擊展開完整結果。測點組的「更多設定」及各方向「本方向設定」保留所有原控制項；有額外組設定、未施測或兩測回時會自動展開。摺疊偏好只存 localStorage 的 tilt-survey-disclosures，不進案件檔；讀數鍵盤依可見欄位使用 next／done。桌機側欄顯示案件摘要；匯出時間沿用案件 lastExportedAt 的資料版次時間。

正常畫面色票與水準測量現行色票對齊。強光與 A4 輸出不套用本次介面色票；既有公式、原始數值、確認、更正及備份格式維持。

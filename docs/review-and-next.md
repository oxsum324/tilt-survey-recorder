# 規格檢視與後續精進

日期：2026-09-30；對照使用者提供的派工規格 V1、資料蒐集筆記與 PNG／SVG 樣張。

## 第一期間已精進的內容

1. **投影前精度**：規格寫「內部整數 mm」，但三維座標驗算 #12 使用六位小數 m，且要求投影誤差小於 0.01 mm。若先把個別座標或位移捨入成 mm，無法同時滿足。實作保留十進位原始精度，先精確相減、再投影，最後才取表列整數 mm。分母仍以表列值計算，讀者可手算核對。
2. **有號測回平均**：左右／前後反向的兩回不可取絕對值平均。實作先轉成方向一致的有號分量，再平均、取絕對值並捨入。較差也採有號分量之差，避免反向讀數被誤判為重複性良好。
3. **草稿與確認分開**：輸入中自動保存，確認後才能輸出。修改已確認讀數必填原因；模式 C 修改立面基準也會使確認失效。
4. **共用垂距獨立輸入**：共用 H 放在測點組設定區；即使其中一向未施測，仍可填 H 供另一向使用。
5. **案件往返穩定**：確認快照採固定欄位排序，避免匯出／匯入正規化後，讀數完全相同卻被誤判更正。
6. **圖面與列印驗證**：幾何測試之外，以 Chrome 實際字型檢查文字外框，另產生並渲染實際 A4 PDF。成果表圖面全黑白、同一 SVG 供螢幕與列印使用。
7. **相對路徑與版本一致**：Service Worker 採整組版本快取；Pages 僅發布明列的程式檔，驗證線上雜湊。未發布任何案件檔、內部參考資料或真實範本。

## 仍需確認

- **B／C 兩測回 H 不同的採用方式**：派工規格只定義 d 取平均，未明確定義 H。第一期先不替使用者決定平均方式，要求兩回 H 一致後才產生成果；請確認後再實作平均或其他規則。此限制只對兩回不同 H 的情況生效，一回與兩回相同 H 均可使用。
- **±3 mm 與兩回較差 3 mm**：手冊的測回誤差文字不能直接推論為統計量測不確定度，也不必然等同兩筆讀數最大差 3 mm。第一期依規格使用可調整提示值，沒有規範通過標示。
- **T／S 語意**：某些手冊以工地相對方向區分 T、S；本工具依樣張用立面內／外。T／S 是可選命名，不會自動宣稱符合特定手冊編碼，後續宜加可填的測線用途欄。
- **N／E 與儀器 X／Y**：待看實際儀器畫面確認，不自動猜軸向。
- **B 的斜交視線**：HD 差在斜交條件下是測站視線方向的量測差，不宜當作已分解到立面方向。第一期保留規格的幾何作業提示。
- **基準朝向一致**：模式 C 的由左至右基準與外法線朝向應彼此相容。後續可加一致性提示及現場羅盤示意，但不自動旋轉使用者輸入。

## V0.3.0 追加功能（2026-10-01）

使用者指出缺少平面圖與點位照片，已依追加要求完成，不再以原分期停止點阻擋這兩項功能。

- 點位照片與測點組關聯；TP／TB 文字框箭頭、圈選、箭頭、自由筆、文字、橡皮擦、復原／重做、長按放大定位。
- 原圖獨立保存；EXIF／匯入時間來源明確；日期戳記可編輯／隱藏；標註 JPEG 最長邊 4096 px。
- 平面圖匯入／貼圖、來源和日期、每組一個點與兩編號、點及標籤拖動、縮放與平移、更換確認清除位置。
- 照片每頁兩張、獨立佈設圖；完整附件可選照片／底圖；系統列印與直接下載影像式 PDF。
- 強光顯示、螢幕常亮狀態、離線媒體讀取、含原始影像的完整案件檔。舊版案件保持相容。

## 接下來的實際驗收

| 情境 | 核對內容 |
|---|---|
| iPhone／Android 實拍 | 照片方向、HEIC 轉 JPEG、EXIF／匯入時間說明與原圖備份 |
| 現場照片標註 | 長按放大、TP／TB 編號、復原、橡皮擦、日期與輸出可讀性 |
| 底圖位置 | 相同點位配對、文字不遮住測點、來源日期、底圖更換後重新佈設 |
| 戶外與離線 | 強光對比、螢幕亮度、常亮長時間與分頁返回、離線拍照和輸出 |
| 一個實際案例 | 方向、H、TP／TB、紙本可讀性、備份再匯入，仍需使用者現場核對 |

資料蒐集中的安全門檻、補償係數與法規版本未納入本工具計算；功能完成不等同結構安全驗證。B／C 兩回 H 不同的採用規則仍維持待確認，未因新增媒體功能而改動。

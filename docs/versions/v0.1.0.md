## 4. 測試結果

- `npm.cmd test`：57／57 通過，0 失敗；包含規格第 5.5 節 15 個案例。
- `npm.cmd run test:browser`：12／12 檢查通過，0 執行錯誤；模式 A／B／C、讀數更正、案件往返、本機保存、離線網址與四種寬度。
- Chrome 實際 SVG 字型文字外框：範本四格無交疊、無出框。
- 實際列印 PDF：A4 直式 3 頁（成果表 1 頁＋原始讀數 2 頁），可選取文字，四個分母一致；逐頁渲染檢視。
- 曾發現並修正：匯出後再匯入，物件欄位排序使確認快照不一致；已補單元與瀏覽器回歸測試，沒有略過檢查。
- 發布後另核對 Pages `deploy-manifest.json` 的 commit 與全部 11 個公開程式檔 SHA-256。`.nojekyll` 是部署中繼檔，納入發布包但 GitHub Pages 不提供 HTTP 讀取，清冊分開記錄。線上結果見交付回報及 GitHub Actions 記錄。
- 線上核對曾遇兩項發布驗證問題並修正：Windows 工作檔 CRLF 與 GitHub LF 的雜湊不同，改為一致 LF 發布；`.nojekyll` 誤列為公開資源而收到 404，修正為部署中繼資料。公開程式檔的逐檔 SHA-256 檢查保留，未略過。

## 6. 已知限制

- iOS、Android 的數字鍵盤、觸控、安裝與系統列印尚待實機測試；± 按鈕已提供負號輸入。
- 目前 B／C 兩測回 H 不同時先不出成果，待確認採用方式。
- 立面是參數化示意；省略樓層時尺寸以標註為準；TB 未量測不編造離地高度。
- 資料只在此瀏覽器，無裝置同步。未確認草稿不可輸出成果，但可保存、匯出備份。
- 預設值是可調整設定，未代表實際建物或規範判定。
- 新版快取需關閉舊工具分頁再重開，既有案件保留在 IndexedDB。

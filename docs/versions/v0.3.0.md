# V0.3.0｜點位照片、標註與平面圖

日期：2026-10-01。使用者追加要求補齊點位照片與平面圖，完成原分期中的現場媒體操作及輸出。

- 相機／相簿／檔案照片，每張歸屬測點組。TP／TB 文字框箭頭、圈選、箭頭、自由筆、文字、橡皮擦、復原／重做與長按放大定位。
- 原始影像不改寫；EXIF／匯入時間明示來源，日期戳記另存並可編輯／隱藏；標註 JPEG 最長邊 4096 px。
- 匯入平面底圖、貼圖、Google 地圖連結；來源及製圖日期；每組一個測點、兩個可拖動測線編號，放大與平移。更換底圖先確認，再清除舊點位。
- A4 照片每頁兩張、獨立佈設圖；完整附件可勾選照片／佈設圖。系統列印和影像式 PDF 下載皆可用。
- 強光模式與螢幕常亮；含照片／底圖原檔的完整案件備份；舊版讀數和確認記錄保持相容。

驗證：66 項單元測試；12 組既有讀數流程、16 組照片／平面圖流程；另外以模擬平台驗證 4 組常亮狀態、2 組舊版快取與案件升級／保存後重載流程。測試使用合成影像與合成案件；原始 bytes 雜湊往返一致。列印照片／佈設圖及完整五頁影像式 PDF 已渲染檢查。320、390、768、1280 px 版面無水平捲動，離線重開可讀全部媒體及附件。

尚待實機驗收：iPhone／Android 相機方向、HEIC 轉檔、剪貼簿權限、戶外強光及長時間常亮。自動測試與模擬平台不代表實機已驗收。B／C 兩回 H 不同的採用規則維持既有待確認限制。

程式來源：annotation.js 圈註核心取自 section-properties-calculator 的 field-survey/annotation.js（641e627d731122d7451aaf1b349e761928efcb6e）；EXIF、儲存、離線與 PDF 整合參考 level-survey-recorder（78f2ae02646510290854e89ff1ba901776bce9f5），複製後獨立演進。原參考專案未修改。html2pdf 授權檔一併保存。

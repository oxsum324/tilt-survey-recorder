# V0.4.1｜手機版面與讀數流程

日期：2026-10-22。承接 V0.4.0 b36e2b4，以 codex/v0.4.1-mobile-layout 分支與 PR 交付，尚未合併或部署。

- N1：640 px 以下單列表頭，四個原狀態控制項收進「狀態」，六步採橫向捲動分段控制，完整名稱保留於 aria-label，目前步驟捲到可見。匯出／匯入／驗證移到案件與成果頁底部；原分享按鈕沿用相同 id，移到目前頁面備份區。頁面說明仍可展開。桌機保留 230 px 側欄並加入案件摘要。
- N2：手機底部 52 px 摘要可展開完整結果，main 預留底部空間；桌機維持 sticky，偏移量依實際表頭高度。強光摘要高對比。
- N3：更多設定與本方向設定只調整介面；非預設組設定有值、未施測或兩測回時自動展開。摺疊狀態存裝置 localStorage，不加入案件檔。輸入 next／done 只巡覽可見欄位。原模型欄位及順序不變。
- N4：副標為「弘一工程 · 鑑定現場工具」，手機標題 20 px，桌機標題尺寸維持。
- N5：尚未取得水準測量 V0.7.1 正式交付回報，依其現行色票對齊：ink #17343b、muted #5d7275、accent #176268、paper #fff、line #d4e0dd、bg #f3f6f5；強光與列印不變。

375 px 的首卡統一以 #workspace 直屬的第一張 section.card 資料輸入卡量測，前後均不納入選擇列表。手機的選擇操作放在標題旁展開控制，保留所有原選取與新增按鈕；桌機仍為原列表。N3 同時驗證預設 A 及自訂角位置／偏距、TB 高度、備註皆有值的情況，一般及強光均保持更多設定展開。精確量測、六頁前後截圖與五次固定 HEAD 瀏覽器測試，以外部派工回報為準。

PR #3 審查修正：強光六步按鈕恢復至少 48 px；中文組字 Enter 與 229 不換欄，next／done 僅處理讀數頁的數字欄位。桌機摘要的上次匯出時間改為本機實際下載交付／分享完成時刻，只存裝置偏好，舊檔缺少操作紀錄明示未記錄，不拿案件資料版本時間代替。原 lastExportedAt、模型順序及備份格式不變。

前次回報將強光首卡寫成 150 px，但原提交實測為 146 px、導覽高度只有 44 px。本次另量測並記錄強光六頁的實際資料卡位置與每顆導覽高度，不沿用先前誤列值；所有八支瀏覽器腳本的斷言都改由等待式檢查。

計算、示意圖、報表、媒體附件、PDF、儲存及指紋模組保持原檔；15 個算例預期值不變。版本 0.4.1、schema 1、Playwright 1.58.2。新增的檔案只有文件與測試，不增加執行期模組、CDN 或第三方套件。CSP 不變。

相容測試涵蓋實際 V0.1.0、V0.3.0、V0.4.0 模型；V0.2 無獨立發布模型，以 V0.1 結構宣告 0.2.0 的合成檔測試，不冒稱實際 V0.2 使用者案件。合併後仍由使用者完成桌上實例、手機實拍及戶外日照／常亮三個實機停止點。歷史私人字串、CI secret、儀器座標對應及 B／C 兩測回不同 H 的規則維持原待決。

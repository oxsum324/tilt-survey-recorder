# V0.4.2｜核對遺留小修

日期：2026-10-22。承接已發布的 V0.4.1 main `bc271925c74944d00fa97cfd38922312403b408b`，由 `codex/v0.4.2-followups` 分支以 PR 交付，尚未合併或部署。

- S1：採短標籤方案，輸入標籤改為「H（cm）」，勾選仍為「兩方向共用垂距 H」。375 px 一般／強光均驗證標籤單行及實際文字範圍未換行，桌機維持勾選與輸入同列。資料欄位、單位及共用垂距規則不變。
- S2：>960 px 讀數頁以 ResizeObserver 量測即時結果列的實際高度，設定桌機頂部捲動留白。留白＝既有 sticky top（實際表頭高度＋8 px）＋結果列高度＋8 px；因此也包含列本身的置頂偏移，避免只加列高仍被遮住。重新產生讀數頁會重新觀察新結果列，內容高度變化時同步更新；離開讀數頁清除量測值。手機底部留白與 A4 輸出不變。

1280×720 px 回歸先確認 T1′ ΔX 中心確實被 sticky 結果列遮住，再以原生 Tab 從上一個可見控制項切入；驗證焦點正確、欄位中心命中輸入框、欄頂位於結果列下方至少 8 px。另改變讀數狀態，核對高度變化後的留白確實跟著更新。CSS 計算值序列化採千分之一 px 精度比較，實際中心命中及上下邊位置斷言不放寬。非讀數頁與手機不套用桌機頂部規則。

S3 跳過：U1 儀器座標軸答案未填，不改 N／E／Z 標示，不推測儀器 X／Y 對應。S4 跳過：U2 仍為未填，沿用既有不同 H 阻擋行為，不自行採平均或第一測回。U3 歷史私人字串本版不處理、不改寫歷史；U4 私人清單及 U5 三個實機停止點維持待決。

版本 0.4.2、schema 1、Playwright 1.58.2。計算、示意圖、報表、媒體報表、PDF、儲存、指紋模組、A4 版面及原 15 算例不變；既有 id／data-* 綁定與 CSP 保留，不增加 CDN 或執行期套件。V0.1／V0.3／V0.4.0／V0.4.1 使用實際歷史模型做相容回歸；V0.2 沿用合成結構相容檔，未聲稱已驗收真實 V0.2 案件。固定提交的三次瀏覽器結果、截圖及 SHA-256 詳外部交付回報。

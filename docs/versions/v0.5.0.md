# 傾斜測量紀錄 V0.5.0

日期為 2026-10-25。依技能檢查與 pstack 複審改善保存、匯入及方向解讀。

## 修正

- 保存以交易內案件識別與修訂比對拒絕舊快照，避免跨分頁覆寫。
- 資料庫升為版本 2，原 stores 與案件保留；舊版程式不能再讀寫。
- 案件取代期間暫停輸入、保存及離頁回存，完成後才切換現案。
- 取代保留既有媒體；同一媒體識別只接受相同內容，拒絕異內容覆寫。
- 指紋失配停止匯入。無指紋舊案仍可讀並明示來源狀態。
- C 八方位取同一座標基準；A、B 有效朝向納入確認與更正。
- 舊快照不改寫；實際方向語義相容時沿用，變更時要求理由。
- 非零合成偏移不再因整數分母為零被稱為未量得偏移。
- 成果表與原始表列計算核心版本。

## 相容與使用

案件 schema 維持 1。原始讀數、媒體識別、內容指紋及更正資料不加入儲存修訂資訊。升級同步 appVersion，案件內容指紋不因此改變。
升級前先匯出完整備份並關閉其他舊版分頁。資料庫版本 2 會拒絕舊版程式的讀寫；新版同版衝突分頁仍可匯出草稿及保留的媒體。
表列算法、不同 H 兩回拒算、超差只提示、刪測點後的附件更正頁範圍均維持。不自動回收未引用媒體。

## 驗證

新增計算與匯入純模組回歸由 npm test 執行。真實 Chrome IndexedDB 與同頁取代時序由 npm run test:storage 執行。既有瀏覽器、桌機、PDF、升級及故障取證門檻保留。
升級測試仍固定舊 V0.4.2 的 27 個原始 runtime。跨版本比較只允許 appVersion 更新為受測版本，其餘案件、媒體與指紋精確比對。發布清單版本與實際 model.js 版本交叉核對。
結果及發布 commit 以當次 CI 與線上 deploy-manifest 為準。尺寸模擬不代表手機實機驗收，合成案例不代表指定實案驗收。

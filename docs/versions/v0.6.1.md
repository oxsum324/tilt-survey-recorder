# 傾斜測量紀錄 V0.6.1｜手機報告預覽與失敗提示

日期：2026-11-05。承接 V0.6.0 正式 main `8a41627`。使用者已授權發布，正式網站僅在完整 GitHub Actions 檢查通過後更新。

## 問題與修正

手機按「更新預覽」後，原畫面仍停在輸出選項，已產生的報告位於視窗下方；產生報告時若遇到例外，原因又只顯示在收合的「狀態」選單內，成果區看起來只有空白。

- 成果頁顯示產生進度、完成頁數與「查看報告預覽」入口。
- 手機按「更新預覽」後，成功時移到報告，失敗時移到成果頁的原因。
- 預覽失敗會結束載入狀態、清除失效報告，修正後可重新預覽。原讀數確認與附件檢查仍保留。
- 更新頁首、啟動網址與內容指紋快取，方便手機確認已載入 V0.6.1。

## 資料與驗證

案件 schema、IndexedDB 版本、讀數、計算、確認／更正快照與原始媒體儲存格式均未更動。更新前可先匯出案件備份；新版資源完整下載後，由「保存並載入新版」或重新整理切換，不清除網站資料。

新增 Chrome／WebKit 375×667、390×844、1280×900 預覽回歸，涵蓋定位、狀態、失敗顯示與恢復、案件內容不變；390 px 另檢查完整五頁附件、獨立照片／佈設圖／成果表與列印狀態，共 28 項。既有 Chrome／Edge 測試保留，CI 安裝加入固定 Playwright 版本的 WebKit。

修正前失敗及本機環境診斷見 [前期修正紀錄](v0.6.0-iphone-preview-fix.md)。該文件記錄發布前狀態，不代替本版發布結果。實際提交、CI 與發布後線上收據另列於發布交付。

WebKit 模擬不等於 iPhone 實機驗收；仍請使用者用原 iPhone／Safari、原案件檢查預覽及 PDF。
